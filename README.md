# Nexora — Responsive Landing Page

**Week 1 Task: Responsive Landing Page Development**

Nexora is a portfolio-ready responsive landing page created using **HTML5, CSS3 and vanilla JavaScript**. The project demonstrates semantic page structure, modern CSS layout techniques, responsive breakpoints and basic JavaScript interaction.

## Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive desktop, tablet and mobile layouts
- CSS Grid and Flexbox
- Mobile navigation menu with JavaScript
- Accessible navigation attributes
- Responsive dashboard-style hero illustration built entirely with CSS
- Smooth scrolling
- No external frameworks or dependencies
- Clean comments and organized files

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Resize the browser window or use DevTools device emulation to test responsiveness.

No installation or build process is required.
