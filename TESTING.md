# Testing Notes

## Responsive breakpoints
- Desktop: above 900px
- Tablet: 701px–900px
- Mobile: up to 700px
- Small phones: up to 420px

## Manual tests
1. Open `index.html` in Chrome, Edge or Firefox.
2. Test the navigation at desktop width.
3. Resize below 700px and open/close the hamburger menu.
4. Select each navigation link and verify smooth scrolling.
5. Test at 320px, 375px, 768px and 1440px viewport widths.
6. Confirm that content does not overflow horizontally.
